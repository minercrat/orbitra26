ORBITRA '26 AVIONICS HARDWARE & COMMUNICATION ARCHITECTURE CHEAT SHEET

1. DUAL ESP32 ARCHITECTURE
• Node 1 (CubeSat): Telemetry transmitter inside satellite.
• Node 2 (Ground Base): Receiver plugged via USB to laptop.
• Protocol: 2.4GHz ESP-NOW (Low latency <15ms, direct peer-to-peer).
• Processor: Xtensa Dual-Core 32-bit LX6 @ 240 MHz.
2. MPU6050 (6-AXIS IMU)
• Function: Measures 3-axis angular velocity and linear acceleration.
• Bus: I2C Interface (Address: 0x68).
• Pins: SDA (GPIO 21), SCL (GPIO 22).
• Filtering: 10Hz Hardware DLPF enabled on register 0x1A.
3. BMP280 (BAROMETER)
• Function: Atmospheric pressure (hPa) & relative altitude via hypsometric formula.
• Bus: Shared I2C Bus (Address: 0x76 / 0x77).
• Filtering: 16x IIR Hardware Filter configured.
4. DHT11 (ENVIRONMENT)
• Function: Chassis internal ambient temperature & relative humidity.
• Bus: 1-Wire Digital Communication on GPIO 4.
• Sampling: Throttled to 2-second intervals.
5. NEO-6M GPS MODULE
• Function: Latitude, Longitude, Doppler Ground Speed, and GPS altitude fallback.
• Bus: HardwareSerial UART2 @ 9600 baud (RX2=16, TX2=17).
