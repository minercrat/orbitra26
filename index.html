STAGE 2 // TECHNICAL INSPECTION & VIVA GUIDE

ORBITRA '26 AVIONICS HARDWARE & COMMUNICATION ARCHITECTURE CHEAT SHEET

1. DUAL ESP32 ARCHITECTURE
• Node 1 (CubeSat): Telemetry transmitter inside satellite.
• Node 2 (Ground Base): Receiver plugged via USB to laptop.
• Protocol: 2.4GHz ESP-NOW (Low latency <15ms, direct peer-to-peer, no router).
• Processor: Xtensa Dual-Core 32-bit LX6 @ 240 MHz.
2. MPU6050 (6-AXIS IMU)
• Function: Measures 3-axis angular velocity and linear acceleration.
• Bus: I2C Interface (Address: 0x68).
• Pins: SDA (GPIO 21), SCL (GPIO 22).
• Voltage: 3.3V power rail.
3. BMP280 (BAROMETER)
• Function: Atmospheric pressure (hPa) & calculated altitude via hypsometric formula.
• Bus: Shared I2C Bus (Address: 0x76).
• Pins: SDA (GPIO 21), SCL (GPIO 22).
• Precision: ±1 hPa (~1 meter altitude resolution).
4. DHT11 (ENVIRONMENT)
• Function: Chassis internal ambient temperature & relative humidity.
• Bus: 1-Wire Digital Communication.
• Pin: DATA (GPIO 4) with 10kΩ pull-up.
• Range: 20-90% RH, 0-50°C.
5. NEO-6M GPS MODULE
• Function: Geolocation, Latitude, Longitude, Doppler Ground Speed.
• Bus: HardwareSerial UART @ 9600 baud.
• Pins: GPS TX → ESP32 RX2 (GPIO 16), GPS RX → ESP32 TX2 (GPIO 17).
• Antenna: Dedicated ceramic patch antenna.
6. POWER SUBSYSTEM (EPS)
• Battery: 2S Li-Ion Cells (7.4V nominal, 8.4V max).
• Protection: 2S 7.4V BMS (Overcharge & over-discharge cut-off).
• Regulation: LM2596 DC-DC Buck Converter steps down 7.4V → 5.0V clean bus.
• Monitoring: Resistor divider network to ADC (GPIO 34).
